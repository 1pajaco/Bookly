# Bookly

Bookly is a library application built with Flutter and Firebase. It provides a simple catalog for books with user authentication and cloud-backed data storage so users can browse, add, edit, and manage books in a shared library.

## Key features
- User authentication (Firebase Auth)
- Privilaged users and standard users
- Book catalog (FireStore)
- Real-time updates and cloud syncing
- Add, edit, delete, borrow/return book actions

## Tech stack
- Flutter (Dart)
- Firebase: Firebase Auth, Cloud Firestore

## Running using flutter in Vscode
COMMANDS:
flutter devices               # list devices connected to your computer
flutter run -d <device_id>    # replace with an ID from that list

EXAMPLES:
flutter run -d chrome ~ run in chrome tab
flutter run -d ad81abd5 ~ example running on phone connected via USB
